# 피크민 데코 컬렉션

피크민 블룸의 데코 피크민 수집 현황을 관리하는 개인용 웹 앱입니다. 서버 없이 동작하는 **단일 HTML 파일**로, iCloud Drive 등으로 동기화해 여러 기기(Mac/iPad/iPhone)에서 브라우저로 바로 열어 씁니다.

## 주요 기능

- **위치별 / 스페셜** 탭으로 카테고리별 데코 피크민 목록과 수집 여부, 보유 개수를 관리. 위치별 일반 데코는 색상별 대기 피크민 수도 함께 관리 (칩에 `데코/대기`로 표시, 희귀·스페셜 등 대기가 없는 데코는 개수만 표시)
- **현황판** 탭에서 구역별 표를 확인
  - 구역: 전체 합계, 위치(희귀 포함), 위치(희귀), 스페셜
  - 항목: 색상별 데코 · 대기(전체 합계와 위치 희귀 포함만) · 수집 종류 · 남은 종류 · 진행도. 진행도의 최고/최저 색상은 강조 표시
  - 표를 누르면 그 표만 "남은 종류" ↔ "전체 종류"로 전환 (선택은 기기에 저장)
  - 아래에 위치 / 스페셜의 미완성 카테고리와 부족한 색상 목록
  - 넓은 화면은 타일 배치, 휴대폰은 구역을 하나씩 선택해서 보기
- 색상 버튼을 눌러 해당 색상만 필터링 (색상 필터와 "미완료만"은 카테고리의 펼침 상태를 바꾸지 않고, 검색어를 입력할 때만 결과를 자동으로 펼침)
- 펼친 카테고리를 내려보는 동안 카테고리 제목과 마릿수가 상단에 고정되며, 고정된 제목을 눌러 바로 접을 수 있음
- **수집 기록과 보유 수를 따로 관리**
  - 한 번이라도 1마리가 되면 수집함으로 남고, 돌려보내거나 희귀로 바뀌어 0마리가 돼도 유지 (초록 테두리만 있는 칩)
  - 종류 수 · 완료 표시 · 진행도 · 미완성 목록 · 희귀 해금은 수집 기록 기준, 마릿수와 5마리 달성은 현재 보유 수 기준
  - 칩을 길게 누르면 보유 마릿수와 "수집함" 표시를 직접 수정
- **되돌리기** 버튼으로 직전 수정 한 번 취소 (새로고침하면 기록이 사라짐)
- 칩의 `−`는 **데코 피크민 돌려보내기**: 개수만 줄고 대기는 늘지 않음. 잘못 입력한 것은 되돌리기로 취소
- 희귀 데코 해금: 해금 전에는 희귀 데코를 숨기고 종류 수 합계에서도 제외. 짝이 되는 일반 데코를 모두 모으면 자동으로 열리고, 이미 게임에서 해금했다면 "이미 해금했어요" 버튼으로 열 수 있고, 이때 짝인 일반 데코를 수집함으로 표시할지 선택 (희귀 개수를 이미 입력한 경우는 해금 상태)
- 희귀 데코 레벨: 희귀가 해금된 카테고리에서 일반 데코 칩 `+`(대기 → 데코)는 200P, 칩 `−`는 20P가 자동 반영되고, 그 밖의 점수는 레벨 배지를 눌러 직접 수정
- 휴대폰에서는 아래로 스크롤하면 상단이 색상 버튼과 탭만 남고 하단 바가 숨음
  - 이때 "접기" 버튼이 켜지며, 다시 누를 때까지 펼쳐지지 않음 (버튼으로 직접 접은 상태는 다음에 열 때도 유지)
  - 접힌 동안 되돌릴 것이 있으면 왼쪽 아래에 되돌리기 버튼 표시
- 상단의 화면 모드 버튼을 누를 때마다 라이트(달) → 다크(해) → 자동(A) 순으로 전환. 자동은 기기 설정을 따라가며, 기본은 라이트
- 두 번 탭과 입력창 선택 때 화면이 확대되지 않음 (두 손가락 확대는 가능)
- 카테고리명 · 아이템명 · 색상을 조합한 **검색 쿼리 문법** 지원 (`&` AND, `;` OR, `!` NOT, `()` 그룹핑, `=` 정확히 일치, `데코`/`대기` 예약어 등)
- 데이터 **백업(JSON 내보내기) / 가져오기**
- 모든 데이터는 브라우저 **localStorage**에 저장되며 서버로 전송되지 않음

## 사용 방법

`index.html`을 브라우저로 열기만 하면 됩니다. 별도 설치나 빌드 과정이 없습니다.

## 데이터 저장 구조

| localStorage 키 | 내용 |
|---|---|
| `pikminDecoCatalog_v2` | 카테고리/아이템 구조 (색상 옵션, 희귀 여부 등) |
| `pikminDecoState_v2` | 보유한 데코 피크민 개수, 수집 기록, 희귀 포인트와 해금 상태 |
| `pikminDecoWait_v1` | 색상별 대기 피크민 개수 |
| `pikminDecoDashView_v1` | 현황판 표별 "남음/전체" 보기 설정 (백업에 포함되지 않음) |
| `pikminDecoFold_v1` | 휴대폰 상단 "접기" 설정 (백업에 포함되지 않음) |
| `pikminDecoTheme_v1` | 화면 모드 선택: 라이트/다크/자동 (백업에 포함되지 않음) |

앱 내 백업 기능으로 위 데이터를 JSON 파일로 내보내고, 필요 시 다시 가져올 수 있습니다.

## 참고

이 저장소에는 개인 수집 데이터(백업 JSON, 진행도 등)는 포함되어 있지 않습니다. `index.html`에는 카탈로그(카테고리/아이템 구조)만 기본값으로 내장되어 있으며, 실제 보유 현황은 각 기기의 localStorage에만 저장됩니다.
