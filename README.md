# 피크민 데코 컬렉션

피크민 블룸의 데코 피크민 수집 현황을 관리하는 개인용 웹 앱입니다. 서버 없이 동작하는 **단일 HTML 파일**로, iCloud Drive 등으로 동기화해 여러 기기(Mac/iPad/iPhone)에서 브라우저로 바로 열어 씁니다.

## 주요 기능

- **위치별 / 스페셜** 탭으로 카테고리별 데코 피크민 목록과 보유 개수, 색상별 대기 피크민 수를 관리
- **현황판** 탭에서 색상 × 항목(데코/대기/활성화 종류/데코 진행도 등) 매트릭스와 미완료 카테고리 목록을 한눈에 확인
- 카테고리명 · 아이템명 · 색상을 조합한 **검색 쿼리 문법** 지원 (`&` AND, `;` OR, `!` NOT, `()` 그룹핑, `=` 정확히 일치, `데코`/`대기` 예약어 등)
- 데이터 **백업(JSON 내보내기) / 가져오기**
- 모든 데이터는 브라우저 **localStorage**에 저장되며 서버로 전송되지 않음

## 사용 방법

`index.html`을 브라우저로 열기만 하면 됩니다. 별도 설치나 빌드 과정이 없습니다.

## 데이터 저장 구조

| localStorage 키 | 내용 |
|---|---|
| `pikminDecoCatalog_v2` | 카테고리/아이템 구조 (색상 옵션, 희귀 여부 등) |
| `pikminDecoState_v2` | 보유한 데코 피크민 개수 |
| `pikminDecoWait_v1` | 색상별 대기 피크민 개수 |

앱 내 백업 기능으로 위 데이터를 JSON 파일로 내보내고, 필요 시 다시 가져올 수 있습니다.

## 참고

이 저장소에는 개인 수집 데이터(백업 JSON, 진행도 등)는 포함되어 있지 않습니다. `index.html`에는 카탈로그(카테고리/아이템 구조)만 기본값으로 내장되어 있으며, 실제 보유 현황은 각 기기의 localStorage에만 저장됩니다.
